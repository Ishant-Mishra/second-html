# HTML Practice Projects

A collection of small HTML exercises and beginner web pages created while learning web development and Git.

## Files

- `Exercise1.html` — HTML exercise.
- `buttons.html` — button and page-element practice.
- `index.html` — portfolio-style page.
- `portfolio.html` — portfolio practice page.
- `project.html` — additional HTML page.
- `html-css-reference.pdf` — HTML/CSS reference material stored with the exercises.

## Open the Pages

Clone the repository and open any HTML file directly in a browser.

```bash
git clone https://github.com/Ishant-Mishra/second-html.git
cd second-html
```

No package installation or build step is needed for the static HTML files.

## Purpose

This is a learning repository rather than a production website. As the exercises evolve, add a short note to each page describing the concept being practised, and keep project-specific code and learning resources clearly organized.
